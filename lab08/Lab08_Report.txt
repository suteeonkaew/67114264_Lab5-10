1. Disk Scheduling:
FCFS moved the disk head 640 cylinders, while SCAN moved it 331 cylinders. SCAN serves requests in one direction before reversing, reducing back-and-forth movement for this request list.

2. I/O Bound Concept:
An I/O-bound task spends much of its time waiting for storage rather than using the CPU. The CPU may be idle or run other tasks while the requested data is being loaded.

3. AI Industry Connection:
Reading many separate files requires repeated file opening, metadata checks, and closing. In my experiment, 1000 files took 0.0232 seconds, while one packed file took 0.0016 seconds. Packing data can reduce loading overhead and help supply batches faster, reducing GPU idle time. GPU utilization was not measured in this experiment.
