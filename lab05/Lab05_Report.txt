1. Address Translation Math (Phase 3):
Assume an OS has a PAGE_SIZE of 4096 bytes. 
If an AI model requests data at Logical Address 10000, calculate:
- The Page Number: 2
- The Offset: 1000
Calculation:
10000 = (2 × 4096) + 1808
Therefore, the page number is 2 and the offset is 1808.

2. Physical Memory Fragmentation:
Paging allows the OS to store pages in available frames even when they are not next to each other. The page table tracks their locations, so the OS does not need one large continuous block of physical RAM.
