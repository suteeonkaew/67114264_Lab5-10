1. The Role of the Operating System:

- File System & Permissions:
os.path.exists(dataset_path) checks whether the file exists. Workload D failed because secret_keys.txt was missing. This check does not verify actual read permissions.

- Memory Management:
The RAM allocation loop makes jobs wait until enough simulated RAM is available. ram_lock protects the shared counter, preventing simultaneous allocations from exceeding the limit.

- Concurrency & Deadlocks:
sorted(req_gpus) makes all jobs acquire GPU locks in the same order. This prevents circular waiting between GPU locks.

- CPU Scheduling Queue:
job_queue stores submitted jobs, and worker threads allow jobs to overlap. This simulates job dispatch rather than Round Robin CPU scheduling.
