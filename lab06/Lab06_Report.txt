1. FIFO vs LRU:
FIFO produced 9 page faults, while LRU produced 7. LRU removes the page that has not been used for the longest time. For this access pattern, keeping recently used pages reduced page faults.

2. Understanding Thrashing:
Thrashing occurs when the OS spends too much time moving pages between RAM and disk. In this simulation, RAM processing took 0.4492 seconds, while file-based processing took 1.4319 seconds, about 3.19 times longer. The script simulates the slowdown using file I/O rather than measuring actual OS swapping.
